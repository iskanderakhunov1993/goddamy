# Карта разведки: Яндекс Практикум, курс «Go-разработчик с нуля» (веб)

Срез: учебный цикл курса — кабинет, программа, урок с теорией, задание в тренажёре, проверка, переход дальше.
Для кого: курс Go на Godemy. Цель — такое же устройство материалов и такой же путь ученика, со своими текстами, задачами и картинками.
Дата: 2026-10-20. Сделано по скилу `replica-recon`.

## Условия и чего мы не берём

«Условия использования сервиса «Яндекс.Практикум»», редакция от 06.03.2026: п. 4.1 и п. 7.2 запрещают копировать, воспроизводить и перерабатывать материалы курсов и использовать информацию сервиса в коммерческих целях без письменного разрешения. Прямого запрета строить конкурирующий продукт нет.

Поэтому:
- берём только устройство: какие экраны, в каком порядке, какие кнопки и как работает проверка;
- не копируем и не пересказываем их тексты уроков, задачи, примеры кода и иллюстрации;
- скриншоты страниц из аккаунта не сохраняем, папка `replica/screens/` пустая; экраны описаны своими словами;
- уроки с кодом в аккаунте закрыты (идут по порядку, для перехода нужна анкета), поэтому экран задания описан по официальной справке, а не по живому экрану.

## Главный цикл

Прочитать короткую теорию → перейти к заданию → написать код в браузере → «Проверить» → при ошибке сообщение и подсказка, при успехе «Далее» → следующее задание урока → следующий урок.

## Сценарии

```
F01 Начать курс
    S01 -> S02 -> S03 -> S04
    кликов до первого урока: 3
    edge: урок закрыт замком; платный модуль

F02 Решить задание
    S04 «Перейти к заданию» -> S05 код -> «Проверить» -> ошибка | «Далее» -> следующее задание (3–5 в уроке) -> следующий урок
    кликов на одно задание: 2 (Проверить, Далее) плюс набор кода
    edge: проверка идёт долго; ошибка показана над заданием

F03 Застрять и выбраться
    S05 -> «Подсказка» | значок теории (S07) | «Сброс» -> «Начать заново»

F04 Перейти к другому уроку из задания
    S05 -> меню курса (S06) -> урок

F05 Вернуться к учёбе
    S01 -> модуль -> тема -> текущий урок
```

## Что не берём

- Тексты уроков, задачи, примеры кода, иллюстрации и маскот — их собственность (п. 4.1 условий).
- Ревьюеры, кураторы, эксперты сопровождения, вебинары — люди, которых у Godemy нет.
- Жёсткие и мягкие дедлайны — решение владельца: курс в своём темпе.
- Оплата, скидки и промо в уроке — у Godemy всё бесплатно, кроме сертификата.
- Подсказки нейросети на их модели.

## Размер

Экранов 10 (берём 8), сценариев 5, сущностей 7. Сложные места: экран задания с несколькими заданиями в уроке и проверкой каждого; задания для 77 уроков без них; Go в браузере работает только через Go Playground (нужен интернет, есть лимиты). Размер: M — несколько недель, основная работа в содержании, а не в интерфейсе.
