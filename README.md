# Godemy

Godemy — бесплатное обучение Go через реальные проекты, спринты и GitHub.

Текущий MVP проводит пользователя от обзора курса до ретроспективы первого проекта — консольного Task Tracker. Курс объясняет необходимые принципы, показывает пример из другой предметной области и оставляет реализацию проекта ученику.

## Возможности MVP

- главная страница и программа курса;
- описание первого проекта;
- подготовительный чек-лист из 12 шагов;
- четыре спринта на одном универсальном шаблоне;
- теория, похожие примеры, самостоятельные задачи и критерии приёмки;
- подсказки, самопроверка и GitHub-процесс;
- форма ретроспективы;
- адаптивная боковая и мобильная навигация.

## Стек

## Учебный контент

Контент отделён от UI в `src/content/goCourse.js`.

- `course` описывает курс и дорожную карту проектов;
- `project` — требования и ожидаемый результат Task Tracker;
- `setupTasks` — подготовительный чек-лист;
- `sprints` — четыре набора данных для универсальной страницы спринта;
- `stages` — порядок этапов и маршруты.

## Как добавить курс

1. Создать новый файл данных по модели `goCourse.js`.
2. Описать курс, проекты, подготовку, спринты и порядок этапов.
3. Переиспользовать общие компоненты либо расширить их через явные свойства.
4. Добавить маршруты в `App.jsx`.
5. Добавить тесты структуры контента и пройти ручной чек-лист.

## Известные ограничения

- прогресс хранится только в состоянии вкладки и пропадает после обновления;
- профиль пользователя и экран завершённого проекта отсутствуют;
- сохранение ретроспективы отключено до выбора серверной БД или временного `localStorage`;
- нет регистрации и синхронизации между устройствами;
- `robots.txt` и `sitemap.xml` используют временный домен `godemy.example`, который нужно заменить перед публикацией;
- проект остаётся React/Vite-прототипом, а не Next.js-приложением.
