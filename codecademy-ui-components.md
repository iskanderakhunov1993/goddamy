# Codecademy UI component reference

Источник: анализ codecademy.com/learn и /catalog. Живой референс (пересобранные компоненты на нейтральном контенте, не оригинальные тексты/фото Codecademy): https://claude.ai/code/artifact/38df3b34-fbfc-4a24-90e0-0b21f54f5284

Используем этот документ как индекс паттернов при обсуждении дизайна — ссылаемся на номер компонента вместо повторного объяснения.

## 1. Header & nav
Тёмная фиксированная полоса ~58px, wordmark в два цвета (белый + акцент), пункты меню — обычный текст без рамок, единственная залитая кнопка на всю панель (Sign Up).

**Статус:** реализовано. `src/App.jsx` (`Header`), стили в `src/styles.css` (`header`, `.logo`, `.login`).

## 2. Announcement bar
Тонкая полоса под шапкой на тёмном фоне: шеврон-иконка + жирный заголовок + подпись + стрелка справа.

**Статус:** не реализовано.

## 3. Hero + signup panel
Заголовок как два «блока» заливки (белый + жёлтый), форма регистрации врезана прямо в hero, а не вынесена отдельным блоком.

**Статус:** реализовано. `src/components/AcademyExperience.jsx` (`PublicGoLanding`), стили `.universal-hero`, `.hero-box`, `.universal-signup` в `src/styles-academy.css`.

## 4. Dual offer cards
Две карточки офферов неравной ширины (~55/45) на общей тёмной подложке; левая — с описанием и кнопкой, правая — почти чистая типографика.

**Статус:** не реализовано.

## 5. Topic tile grid
Плотная сетка 4 колонок из тонких аутлайн-плиток с иконкой и лейблом — навигация-индекс, не карточки с весом.

**Статус:** частично — есть `.universal-course-pills` (пилюли-фильтры), но не плиточная сетка направлений.

## 6. Interstitial modal
Промо-модалка по центру: иконка → заголовок → 2 абзаца → жёлтая кнопка на всю ширину.

**Статус:** не реализовано (есть только `CourseOutline`/`course-modal` для программы курса — другой сценарий).

## 7. Filter sidebar
Левая колонка чекбоксов-фильтров, счётчик результатов жирным в верхней части основной колонки.

**Статус:** не реализовано (каталог Godemy не фильтруется через сайдбар).

## 8. Module / course card ⭐
Главный компонент. Полноширинная цветная плашка-статус сверху (сейчас/доступно/скоро), заголовок, описание, **пунктирный** (не сплошной) разделитель перед футером с метаданными.

**Статус:** реализовано и применяется на всех курсах. `.module-card`, `.module-card-tag` (`.now`/`.open`/`.locked`), `.module-card-footer` в `src/styles-dashboard.css`; вёрстка в `src/components/LearningPages.jsx` (`CoursePage`) и `src/components/CourseCabinet.jsx` (SQL/Python/Product/QA).

## 9. Horizontal carousel
Ряд карточек со стрелками prev/next на уровне заголовка секции (не поверх карточек) + угловой ribbon-бейдж для акций.

**Статус:** не реализовано.

---

### Как использовать
Когда просишь применить паттерн — просто укажи номер и куда: например «сделай на главной topic tile grid (№5) вместо текущего списка направлений» или «добавь announcement bar (№2) над hero». Так не придётся каждый раз пересылать скриншоты.
