# Go Backend: программа буткемпа

Решение владельца от 12 октября 2026 года. Курс Go перестраивается так, чтобы после него ученик умел делать рабочие задачи руками: получить задачу, разобраться в документации, написать сервис, запушить его и пройти проверку.

## Принцип

Сначала общая база, потом спринты. Один спринт — один проект — около недели в свободном темпе. Проекты идут от простых к сложным и отличаются друг от друга предметной областью и стеком: каждый добавляет новый навык к уже имеющимся.

Темы проектов подобраны по мотивам [roadmap.sh/backend/projects](https://roadmap.sh/backend/projects), порядок тем языка сверен с [roadmap.sh/golang](https://roadmap.sh/golang). Тексты задач, контракты и проверки курс пишет сам.

## Формат спринта

Порядок повторяет рабочую неделю в команде. Все термины объясняются заранее, в модуле 2.

1. **Задача.** Тикет от роли «Тимлид»: контекст, что сделать, контракт, критерии приёмки, что не входит. Без имён, компании и сюжета.
2. **Изучи.** Короткие уроки с примерами, которые запускаются в браузере, и квизом в конце. Ссылки на документацию. «Пример соседней команды»: тот же приём на другой предметной области, не решение задачи.
3. **Сделай.** Чек-лист подготовки репозитория и Kanban-доска из карточек задачи. В колонке «В работе» лимит одна карточка. Карточки совпадают с шагами отчёта проверки.
4. **Сдай.** `go run check.go` у себя, тот же скрипт в GitHub Actions при каждом push, затем ссылка на репозиторий. Сайт читает открытый API GitHub и принимает спринт, если файлы проверки не изменены, а последний запуск зелёный.
5. **Ретро.** Три вопроса: что получилось, что мешало, что сделаю иначе. Список навыков и стек спринта.

## Как добавить спринт

1. Написать задачу и контракт, выбрать предметную область, которой ещё не было.
2. Написать эталонное решение в `examples/<id>-solution/` (в git не попадает).
3. Написать `public/go-sprints/<id>/check.go` и `godemy-check.yml`. Проверить на четырёх вариантах: эталон проходит всё, «hello world» почти ничего, наивное решение новичка около половины, эталон с одной типичной ошибкой стабильно падает на нужной проверке. Числа записать в AGENTS.md.
4. Написать уроки теории: каждый пример запустить локально и в Go Playground, каждую ссылку открыть. Примеры — на других предметных областях.
5. Добавить спринт в `src/content/goSprints.js`, модуль с теорией в `src/content/courseCurriculum.js`, уроки в `src/content/lessonContent/`.
6. `npm test`: `tests/bootcamp.test.mjs` сверит карточки доски с шагами проверки, уроки с программой и формат задачи.

## Что проверено в пилоте

- Bookmarks API: эталон 41 из 41 (macOS и Linux в контейнере `golang`), «hello world» 3 из 41, наивный сервер 18–19 из 41, эталон без мьютекса 38 из 41 в каждом запуске.
- Все примеры Go из уроков спринта запущены локально и в Go Playground.
- Приёмка по ссылке проверена автотестами на подменённых ответах GitHub и вживую на тестовом репозитории с GitHub Actions: зелёный запуск (41 из 41, с детектором гонок) сайт принял, красный запуск (версия без мьютекса, 39 из 41) отклонил со ссылкой на запуск. После теста репозиторий закрыт.
