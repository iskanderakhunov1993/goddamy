Маршруты: метод и путь

В API один путь обслуживает несколько действий: GET /books/7 читает книгу, DELETE /books/7 её удаляет. Начиная с Go 1.22 метод и параметры пути записывают прямо в шаблоне маршрута.

  • "GET /books" — только метод GET и только этот путь.
  • "GET /books/{id}" — на месте {id} может стоять любой один кусок пути. Значение достают через r.PathValue("id").
  • Путь совпал, а метод нет — маршрутизатор сам отвечает 405.
  • Не совпало ничего — он сам отвечает 404.

r.PathValue("id") всегда возвращает строку. Запрос GET /books/abc тоже попадёт в этот хэндлер, поэтому строку превращают в число через strconv.Atoi и проверяют ошибку. Не число — это ошибка клиента, код 400.

На сервере есть только маршрут "GET /books/{id}". Что получит клиент на DELETE /books/7?

Чтение, изменение, удаление

GET, PUT и DELETE для /bookmarks/{id}. В уроке те же приёмы показаны на книгах, в проекте их нужно перенести на закладки.

Что из урока пригодится

  • Записать маршрут с методом и параметром пути
  • Достать параметр через r.PathValue
  • Объяснить, когда сервер сам отвечает 404 и 405

PUT /bookmarks/{id}200 и изменённая закладка. 404 и 400, как у POST и GET
DELETE /bookmarks/{id}204 без тела. 404: нет такой закладки
