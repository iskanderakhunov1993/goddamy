# Ручной чек-лист Godemy

## Основной маршрут

- [ ] Главная открывается без пустого состояния и горизонтального скролла.
- [ ] Кнопка начала обучения открывает `/go`.
- [ ] Доступный проект открывает `/go/task-tracker`.
- [ ] Кнопка подготовки открывает `/go/task-tracker/setup`.
- [ ] Каждый прямой URL `/go/task-tracker/sprint/1`–`4` открывает нужный спринт.
- [ ] Боковая навигация переключает этапы на десктопе.
- [ ] Мобильный select переключает этапы.
- [ ] Кнопки «Назад» и «Следующий этап» ведут на ожидаемый экран.
- [ ] Ретроспектива открывается по прямому URL.
- [ ] Сохранение ретроспективы явно обозначено как недоступное.

## Чек-листы и подсказки

- [ ] Пункт чек-листа переключается мышью.
- [ ] Пункт чек-листа переключается клавишами Tab и Enter/Space.
- [ ] Счётчик и процент обновляются после переключения.
- [ ] Раскрытая инструкция показывает объяснение, проверку и типичную ошибку.
- [ ] Подсказка открывается и закрывается повторным нажатием.
- [ ] Незавершённые предыдущие этапы не отмечаются завершёнными автоматически.

## Формы и доступность

- [ ] Каждое поле ретроспективы имеет видимый label.
- [ ] Некорректный URL не проходит встроенную браузерную проверку.
- [ ] Фокус виден на кнопках, ссылках, полях и переключателях.
- [ ] Иерархия заголовков понятна при навигации скринридером.
- [ ] При `prefers-reduced-motion` переходы практически отключены.
- [ ] Контраст текста и кнопок проверен инструментом браузера.

## Адаптивность

- [ ] 390 × 844: нет горизонтального скролла, меню и этапы доступны.
- [ ] 834 × 1194: карточки и формы не переполняются.
- [ ] 1280 × 800: боковая навигация и текст помещаются.
- [ ] 1440 × 1024 и шире: строки текста остаются читаемыми.

## Регрессия и ошибки

- [ ] Обновление каждой страницы сохраняет корректный маршрут.
- [ ] Неизвестный маршрут не показывает пустой экран.
- [ ] В консоли браузера нет ошибок и предупреждений.
- [ ] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` и `npm run test:sites` проходят.

## Заблокировано до реализации прогресса

- [ ] Состояние чек-листа восстанавливается после обновления.
- [ ] Повреждённые сохранённые данные обрабатываются безопасно.
- [ ] Профиль показывает реальный прогресс.
- [ ] Сброс прогресса требует подтверждения.
- [ ] После ретроспективы появляется экран завершённого проекта.
