## Продукт
- Что это (одно предложение): бесплатное обучение IT через реальные проекты, спринты и GitHub — ученик делает настоящий проект у себя на компьютере и проверяет его скриптом.
- Исходная идея (README): курс Go, который проводит ученика от обзора курса до ретроспективы первого проекта — консольного Task Tracker; курс объясняет принципы, показывает пример из другой предметной области и оставляет реализацию ученику.
- Направления сейчас: Go (основной), Python, SQL, QA, Кибербезопасность, Kubernetes и Kafka, YouTube с нуля, «Python для школьников». Статус каждого — в AGENTS.md.
- Путь ученика (Go): главная → курс `/go` → проект `/go/task-tracker` → подготовка (12 шагов) → спринты 1–4 → ретроспектива. Проект проверяется скриптом `check.go` на компьютере ученика.
- Для кого: _уточнить у владельца_.
- Главная ценность: практика вместо теории — 90% работы ученик делает сам, а автоматическая проверка честно показывает, готов ли результат.
- Модель: курс и тренажёр бесплатны всегда; подписка открывает только сертификат.

## Стек и окружение
- Фреймворк / язык: React 19 + Vite 6, JavaScript с проверкой TypeScript (`tsc --noEmit`, `checkJs`), CSS, Phosphor Icons.
- Выполнение кода учеников в браузере: Pyodide (Python, в т.ч. SQL-примеры на sqlite3), sql.js (SQL-тренажёр), play.golang.org (Go).
- Данные: `localStorage` как быстрый кэш + Supabase Postgres (`public.user_state`, миграции в `supabase/migrations/`), вход по ссылке на почту, необязательный.
- Продакшен URL: https://godemy.vercel.app (Vercel, проект `godemy`) — основной адрес по решению владельца. Домен godemy.ru привязан в Vercel, но пока не используется.
- Деплой: вручную через `vercel --prod` (автодеплоя из GitHub нет). Только после явного «да» владельца.
- Превью: Vercel preview на ветку — сейчас не настроено (Git-интеграции нет).
- База данных: прод Supabase трогает только владелец; миграции — в `supabase/migrations/` (SQL показывать владельцу до применения).
- Переменные окружения (значения не хранить в репозитории): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_EDITOR_ALLOWED_EMAIL`. Без них сайт работает, но без входа и облачной синхронизации.
- Команды: `npm run dev` (порт 5180 в `.claude/launch.json`) / `npm run build` / `npm test` / `npm run lint` / `npm run typecheck` / `npm run test:sites`.
- CI: `.github/workflows/ci.yml` — typecheck, lint, test, build.
- Проверочные скрипты проектов и эталоны: `public/*/check.*`, эталоны в `examples/` (в git не попадают). Как перепроверять — в AGENTS.md.

## Правила текста и дизайна
- Тон: _уточнить у владельца_. Сейчас: взрослые курсы — «вы» в тренажёрах и «ты» в части уроков (не унифицировано); детский курс — «ты».
- Запрещённые формулировки: _уточнить у владельца_. Уже действует (AGENTS.md): никакой вымышленной компании, сюжета, персонажей и их иллюстраций; не выдавать непроверенное за работающее (Kubernetes-проект — «в разработке»); не называть выполнением то, что им не является.
- Дизайн-система: светлая тема кабинетов (`#eef1fb`, акцент `#4b3aeb`), тёмная шапка лендинга с жёлтым акцентом — расхождение известное, при правках сводить к одному.
